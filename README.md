# Освоение месторождений Обско-Тазовской губы

Статический сайт — домашнее задание по дисциплине «Основы освоения морских нефтяных и газовых месторождений» (РГУ нефти и газа имени И.М. Губкина).

Чистый HTML/CSS/JS, без сборки и зависимостей — открывается прямо из файла или через любой статический хостинг.

## Локальный запуск

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и запушить в него содержимое этой папки (ветка `main`).
2. В репозитории: **Settings → Pages → Source** → `Deploy from a branch` → ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
